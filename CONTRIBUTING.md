# Contributing

Thank you for your interest in contributing to this series.

## How to Contribute

1. **Report issues** — If you find outdated statistics, broken links, or factual errors, open an issue with the relevant source.
2. **Suggest additions** — Open an issue describing what topic or data point should be added, with a credible source.
3. **Submit corrections** — Fork the repo, make your changes, and open a pull request.

## Guidelines

- All statistics must include a verifiable source (vendor report, research paper, or official publication).
- Keep language concise and technical. Avoid marketing language.
- Follow the existing file structure and formatting conventions.
- No emojis or icons in content.

## Style

- Use Markdown tables for structured data.
- Use code blocks for architecture diagrams and command examples.
- Cite sources inline or in the references file.
- Write in a mix of Vietnamese and English consistent with the existing series.
